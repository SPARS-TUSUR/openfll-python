# Изменения C++-части для Python API

Исходники C++ находятся в закрытом репозитории
`SPARS-TUSUR/fuzzy-logic-library`. Расширения подготовлены в ветке
`python-serialization`, коммит `047e77794458a844047e45c483ff37715edab303`,
на основе `python/pybind@4b2bfe286d131065092e2a5932b3bc0b777d0b0f`.

Сценарий сборки Python-пакета получает этот коммит из закрытого репозитория
через `OPENFLL_BACKEND_TOKEN_SECRET`. Патч с исходниками ядра в публичный
Python-репозиторий не включается. Локальные файлы `backend-patches/*.patch`
исключены из Git; патч в ранее подготовленном архиве предназначен для передачи
разработчикам, имеющим доступ к исходникам.

Добавлены плоский API модели Мамдани, выбор дефаззификатора, получение имён
переменных, вычисление степени принадлежности, доступ к `IModel`, пути Unicode
и сохранение/восстановление моделей. Исправлены однотермовые правила, отключённые
консеквенты нескольких выходов и порядок выходов при загрузке.

Для проверки кода нужны два PR:

- в `fuzzy-logic-library`: из `python-serialization` в `python/pybind`;
- в `openfll-python`: из `python-serialization` в `main`.

При сборке достаточно загрузить закреплённый коммит C++-репозитория. Повторно
применять к нему патч расширений не требуется. Сценарий выпуска сохраняет
поддержку официального Windows CPython 3.14 из актуальной ветки `main`.

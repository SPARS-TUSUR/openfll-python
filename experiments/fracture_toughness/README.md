# Валидация нечёткой поверхности трещиностойкости

Эксперимент строит модель Такаги–Сугено нулевого порядка `KIC(P, a, c)` по очищенной выборке из 26 экспериментальных наблюдений. Для итогового расчёта поверхности модель обучается на всех 26 точках. Оценка обобщающей способности выполняется отдельно: на стратифицированном разбиении 20/6 и с помощью повторной стратифицированной 5-кратной кросс-валидации. На каждом разбиении правила и функции принадлежности строятся заново только по обучающей части.

## Построение модели

- Каждое наблюдение формирует одно правило и один постоянный консеквент.
- Консеквенты равны положительным значениям `KIC` из таблицы и не переобучаются.
- Для `P` используются 3 гауссовых множества, для `a` и `c` — по 26 множеств.
- В OpenFLL, Simpful и независимом расчёте NumPy используется t-норма произведения.
- Центры функций принадлежности задаются экспериментальными значениями, ширины определяются по соседним центрам.

Рассчитываются поверхности `100 × 100` для концентраций 0,0; 0,1; 0,2; 0,3; 0,4 и 0,5 масс. %. Значения `P` для промежуточных концентраций определяются кусочно-линейной интерполяцией трёх измеренных пар. Дополнительно вычисляется средний отклик поверхности во всём измеренном диапазоне `P` с шагом 0,1.

## Проверка на экспериментальных данных

Фиксированное стратифицированное разбиение (`random_state=42`) содержит 20 обучающих и 6 тестовых записей — по две тестовые точки для каждого из трёх значений `P`. Получены `RMSE = 0,15849`, `MAE = 0,13731`, максимальная абсолютная ошибка `0,24112`, `R² = 0,39553`. Это единичное разбиение чувствительно к выбору шести точек.

Основная оценка надёжности — 10 повторов 5-кратной стратифицированной кросс-валидации. Построено 50 моделей, каждая из 26 точек была тестовой ровно 10 раз; всего получено 260 независимых от соответствующего обучения прогнозов. Итоговые метрики: `RMSE = 0,15694`, `MAE = 0,12139`, `R² = 0,59744`. По отдельным повторам: `RMSE = 0,15558 ± 0,02173`, `MAE = 0,12139 ± 0,01115`, `R² = 0,59744 ± 0,11445` (среднее ± выборочное стандартное отклонение).

## Проверка по данным Ниихары

26 экспериментальных записей остаются единственной обучающей выборкой. Полный теоретический массив из 30 000 точек подключается только после построения модели и не влияет на правила, функции принадлежности или консеквенты.

Программа принимает либо единый CSV с колонками `P,a,c,KIC`, либо две согласованные книги Excel:

- predictors: `a`, `c`, `P` и необязательная контрольная колонка `c/a`;
- response: `Kc` или `KIC`.

Запуск с двумя книгами Excel:

```powershell
& "$env:TEMP\openfll-py314-fracture-exp\bin\python.exe" `
  -m experiments.fracture_toughness.run_experiment `
  --niihara-predictors-xlsx "C:\path\to\Training Data_predictors.xlsx" `
  --niihara-response-xlsx "C:\path\to\Training Data_response.xlsx"
```

Для предоставленного массива все 30 000 прогнозов конечны. Получены `MSE = 0,05846`, `RMSE = 0,24179`, `MAE = 0,18718`, максимальная абсолютная ошибка `0,89400`, `R² = 0,50949`. Эти значения показывают умеренное, но не точное воспроизведение теоретической поверхности текущей моделью с детерминированными функциями принадлежности. Среднее смещение равно `−0,01418`, медианная абсолютная ошибка — `0,14676`, 95-й процентиль абсолютной ошибки — `0,49953`. Ошибка не превышает `0,10` для 36,50 % точек и `0,20` для 62,08 % точек. Наибольшая ошибка возникает при `P = 7,96274`, `a = 38,415`, `c = 96,28242`: модель прогнозирует `1,05631` вместо `1,95031`.

В `summary.json` записываются общие метрики, диагностика ошибок и результаты экспериментальной валидации. Таблицы разбиения и кросс-валидации сохраняются в `experimental_*.csv`, срезы ошибок теоретической поверхности — в `niihara_error_analysis.csv`. Полная таблица теоретических прогнозов воспроизводимо генерируется как `niihara_reference_predictions.csv`. Дополнительно создаются графики соответствия и карты абсолютной ошибки.

## Запуск на Windows

Нативный модуль проекта собран для MSYS2/UCRT64 Python 3.14:

```powershell
$experimentVenv = Join-Path $env:TEMP 'openfll-py314-fracture-exp'
C:\msys64\ucrt64\bin\python.exe -m venv --system-site-packages $experimentVenv
& "$experimentVenv\bin\python.exe" -m pip install --no-deps -r experiments\fracture_toughness\requirements.txt

$env:PYTHONPATH = "$(Get-Location)\src;$(Get-Location)"
$env:PATH = "C:\msys64\ucrt64\bin;$env:PATH"
& "$experimentVenv\bin\python.exe" -m experiments.fracture_toughness.run_experiment
```

Результаты сохраняются в `experiments/fracture_toughness/results/`.

## Автоматические проверки

```powershell
& "$experimentVenv\bin\python.exe" -m pytest -q
```

OpenFLL и NumPy проверяются на всех 60 000 точках шести поверхностей, на полном проходе по `P` и на всех тестовых прогнозах кросс-валидации. Simpful проверяется на всех 26 точках итоговой модели и на стратифицированной выборке из 300 точек поверхностей.

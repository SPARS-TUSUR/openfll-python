# Валидация нечёткой поверхности трещиностойкости

Эксперимент строит модель Такаги–Сугено нулевого порядка `KIC(P, a, c)` непосредственно по очищенной выборке из 26 экспериментальных наблюдений. Все 26 точек используются для обучения, кластеризация и выделение тестовой части из них не выполняются.

## Построение модели

- Каждое наблюдение формирует одно правило и один постоянный консеквент.
- Консеквенты равны положительным значениям `KIC` из таблицы и не переобучаются.
- Для `P` используются 3 гауссовых множества, для `a` и `c` — по 26 множеств.
- В OpenFLL, Simpful и независимом расчёте NumPy используется t-норма произведения.
- Центры функций принадлежности задаются экспериментальными значениями, ширины определяются по соседним центрам.

Рассчитываются поверхности `100 × 100` для концентраций 0,0; 0,1; 0,2; 0,3; 0,4 и 0,5 масс. %. Значения `P` для промежуточных концентраций определяются кусочно-линейной интерполяцией трёх измеренных пар. Дополнительно вычисляется средний отклик поверхности во всём измеренном диапазоне `P` с шагом 0,1.

## Проверка по данным Ниихары

В предоставленных файлах нет полного массива модельных значений Ниихары и физических параметров, необходимых для его независимого восстановления. Поэтому программа не калибрует «тестовые» значения по тем же 26 обучающим точкам.

Если преподаватель предоставит эталонный CSV с колонками `P,a,c,KIC`, его можно передать отдельно:

```powershell
& "$env:TEMP\openfll-py314-fracture-exp\bin\python.exe" `
  -m experiments.fracture_toughness.run_experiment `
  --niihara-reference C:\path\to\niihara_reference.csv
```

Тогда в `summary.json` будут записаны метрики на независимой модельной выборке, а в `niihara_reference_predictions.csv` — отдельные прогнозы и ошибки.

## Запуск на Windows

Нативный модуль проекта собран для MSYS2/UCRT64 Python 3.14:

```powershell
$experimentVenv = Join-Path $env:TEMP 'openfll-py314-fracture-exp'
C:\msys64\ucrt64\bin\python.exe -m venv --system-site-packages $experimentVenv
& "$experimentVenv\bin\python.exe" -m pip install --no-deps -r experiments\fracture_toughness\requirements.txt

$env:PYTHONPATH = "$(Get-Location)\src;$(Get-Location)"
$env:PATH = "C:\msys64\ucrt64\bin;$env:PATH"
& "$experimentVenv\bin\python.exe" -m experiments.fracture_toughness.run_experiment
```

Результаты сохраняются в `experiments/fracture_toughness/results/`.

## Автоматические проверки

```powershell
& "$experimentVenv\bin\python.exe" -m pytest -q
```

OpenFLL и NumPy проверяются на всех 60 000 точках шести поверхностей и на полном проходе по `P`. Simpful проверяется на всех 26 обучающих точках и на стратифицированной выборке из 300 точек поверхностей.

# Валидация нечёткой поверхности трещиностойкости

Эксперимент строит модель Такаги–Сугено нулевого порядка `KIC(P, a, c)` по очищенной выборке из 26 экспериментальных наблюдений. Для итогового расчёта поверхности модель обучается на всех 26 точках. Оценка обобщающей способности выполняется отдельно: на стратифицированном разбиении 20/6 и с помощью повторной стратифицированной 5-кратной кросс-валидации. На каждом разбиении правила и функции принадлежности строятся заново только по обучающей части.

## Построение модели

- Каждое наблюдение формирует одно правило и один постоянный консеквент.
- Консеквенты равны положительным значениям `KIC` из таблицы и не переобучаются.
- Для `P` используются 3 гауссовых множества, для `a` и `c` — по 26 множеств.
- В OpenFLL, Simpful и независимом расчёте NumPy используется t-норма произведения.
- Центры функций принадлежности задаются экспериментальными значениями, ширины определяются по соседним центрам.

Рассчитываются поверхности `100 × 100` для концентраций 0,0; 0,1; 0,2; 0,3; 0,4 и 0,5 масс. %. Значения `P` для промежуточных концентраций определяются кусочно-линейной интерполяцией трёх измеренных пар. Дополнительно вычисляется средний отклик поверхности во всём измеренном диапазоне `P` с шагом 0,1.

## Проверка на экспериментальных данных

Фиксированное стратифицированное разбиение (`random_state=42`) содержит 20 обучающих и 6 тестовых записей — по две тестовые точки для каждого из трёх значений `P`. Получены `RMSE = 0,15849`, `MAE = 0,13731`, максимальная абсолютная ошибка `0,24112`, `R² = 0,39553`. Это единичное разбиение чувствительно к выбору шести точек.

Основная оценка надёжности — 10 повторов 5-кратной стратифицированной кросс-валидации. Построено 50 моделей, каждая из 26 точек была тестовой ровно 10 раз; всего получено 260 независимых от соответствующего обучения прогнозов. Итоговые метрики: `RMSE = 0,15694`, `MAE = 0,12139`, `R² = 0,59744`. По отдельным повторам: `RMSE = 0,15558 ± 0,02173`, `MAE = 0,12139 ± 0,01115`, `R² = 0,59744 ± 0,11445` (среднее ± выборочное стандартное отклонение).

Эти значения показывают умеренное, но не точное воспроизведение теоретической поверхности текущей моделью с детерминированными функциями принадлежности. Таким образом, сокращение обучения ухудшает результат заметно, но не катастрофически. Средняя абсолютная разница прогнозов двух моделей на общей сетке равна `0,10829`.

## Подбор параметров генетическим алгоритмом

Отдельный эксперимент `ga_evaluation.py` сравнивает исходную модель с нативным
GA. На каждом обучении правила, исходные MF и границы параметров строятся
по текущей обучающей части. Проверяются два режима:

- центры и ширины MF обучаются, заключения ограничены соседними значениями
  `float64` вокруг экспериментального KIC, с максимальным отклонением один ULP;
- центры, ширины и положительные константы заключений обучаются совместно.

Первый режим сохраняет заключения с точностью округления. C++ API требует
строго различающиеся границы, поэтому абсолютная фиксация отдельного параметра
через `set_mf_bounds` пока недоступна. Второй режим меняет исходную постановку
с фиксированными экспериментальными заключениями и оценивается отдельно.

`GridSearchCV` и `RandomizedSearchCV` получают по четыре конфигурации, одинаковые
внутренние фолды и одинаковый бюджет GA. Оба поиска используют диапазоны
`center_radius` от 0,25 до 0,75 и `mutation_rate` от 0,1 до 0,3. Сетка проверяет
четыре угловые комбинации, случайный поиск выбирает четыре комбинации из 25,
включая промежуточные значения. Вложенная стратифицированная проверка
использует пять внешних и три внутренних фолда. Дополнительно проверяется
прежнее разбиение 20/6. Для каждого метода выполняются запуски с seed 7, 19 и 42.
Внешний теоретический эталон подключается после выбора настроек на физических
данных. Он не участвует в подборе параметров.

Для запуска требуется Python с GA-enabled расширением `PyFLL._core` и
зависимости `scikit-learn`, `matplotlib`, `openpyxl`:

```powershell
python -m experiments.fracture_toughness.ga_evaluation `
  --niihara-predictors-xlsx "C:\path\to\Training Data_predictors.xlsx" `
  --niihara-response-xlsx "C:\path\to\Training Data_response.xlsx"
```

Без аргументов Excel выполняется проверка на 26 физических наблюдениях.
Результаты записываются отдельно в `ga_results/`: `metrics.csv`, `metrics_summary.csv`,
`predictions.csv`, `candidates.csv`, `loss_history.csv`, `splits.csv`,
`summary.json` и графики. JSON-файлы обученных движков воспроизводятся
при запуске и игнорируются Git. Seed и бюджет можно изменить аргументами
`--seeds`, `--population-size`, `--generations`.

Из-за 26 наблюдений оценка чувствительна к разбиению. Стратификация по пористости
проверяет прогноз новых измерений при представленных уровнях P. Проверка
переноса на полностью новый уровень пористости потребует отдельного протокола.

## Расширенный этап — устойчивость и регуляризация

Расширенный этап запускается модулем `stability_evaluation`:

```powershell
python -m experiments.fracture_toughness.stability_evaluation `
  --raw-experimental-xlsx "C:\path\to\full_experimental_data.xlsx" `
  --niihara-predictors-xlsx "C:\path\to\Training Data_predictors.xlsx" `
  --niihara-response-xlsx "C:\path\to\Training Data_response.xlsx"
```

Для него требуется собрать C++-ветку `branch/ga-sklearn/experiment` с новыми
аргументами `fit_ga(deviation_penalty=..., narrow_sigma_penalty=...)`.
Коммит backend — `2253725c771bf9d2950ec10a1953615c5ac48268`. В этой Python-ветке
wheel workflow закреплён на нём и проверяет наличие обоих аргументов.
Это зависимость от экспериментальной C++-ветки до её интеграции в
`python/pybind`.
Обычная сборка backend `2151216` поддерживает первый этап эксперимента.

В расширенном этапе сравниваются исходная модель, широкая настройка MF,
три изменяемые ширины Gaussian MF пористости P, увеличенный бюджет и штрафы.
Ограниченный вариант использует диапазон 0,8–1,2 от исходных ширин. Это
рабочее ограничение эксперимента; физическое обоснование границ ещё требуется.
Центры, ширины для a/c и заключения удерживаются в соседних шагах float64.
Нативная хромосома сохраняет размер, но значимые диапазоны имеют три параметра.

Используются три повторения пяти внешних фолдов и пять seed — 7, 19, 42,
73, 101. Ограниченный и широкий варианты получают бюджет 24×40, увеличенный
вариант — 48×120. Штраф выбирается во внутренних трёх фолдах из пяти вариантов
(без штрафа, коэффициенты 0,3 или 3 для отклонения либо сужения ширин).
Безразмерные коэффициенты умножаются на дисперсию y текущей обучающей части.
Нативная целевая функция содержит ошибку данных и средний квадрат
log(sigma/sigma_initial), либо его отрицательной части. Коэффициент штрафа
имеет единицы MSE. Внешняя проверка оценивает обычную ошибку прогноза.

Кривые обучения используют вложенные стратифицированные подвыборки
50%, 75% и 100% обучающей части на одинаковых внешних тестовых точках.
Для кривых используются первые три seed — 7, 19, 42.
Время в таблице metrics включает дополнительные вычисления кривых там,
где они выполняются. Бюджет сопоставляется по популяции и поколениям.

Исходный Excel содержит 35 строк, включая 26 очищенных и девять ранее
исключённых. Эти девять строк имеют неподтверждённый статус и рассматриваются
в отдельном анализе чувствительности. В одном внутреннем разбиении точка
с c=172,37 даёт NaN уже у исходной модели из-за численного обнуления
гауссовых степеней принадлежности при экстраполяции. Поэтому подбор штрафа
на этой таблице исключён из протокола. Диагностика записана в
`stability_results/raw_cv_nonfinite.csv`, состав строк — в `raw_data_audit.csv`.
Оценки 26 и 35 строк относятся к разным контрольным выборкам.

Результаты расширенного этапа находятся в `stability_results/`. Для очищенной
выборки получены следующие медианные RMSE:

| Вариант | Повторная внешняя CV | Теория Ниихары |
|---|---:|---:|
| Исходная модель | 0,15033 | 0,24179 |
| Широкая настройка MF, фиксированная конфигурация | 0,14330 | 0,26119 |
| Три ширины P, 24×40 | 0,15164 | 0,23782 |
| Три ширины P, 48×120 | 0,15164 | 0,23782 |
| Три ширины P со штрафом, выбранным внутри CV | 0,15126 | 0,23782 |

У исходной модели три оценки по внешним повторениям; у GA — 15 оценок
(три повторения × пять seed). Это зависимые оценки на одной выборке из
26 наблюдений. Диапазоны характеризуют разбиения и стохастическое обучение.

Широкая настройка улучшила ошибку в 9 из 15 пар относительно исходной модели
на тех же внешних фолдах. Медианное парное изменение RMSE — минус 6,03%.
Медиана разброса max–min между seed внутри одного внешнего повторения —
0,05745. Этот контрольный вариант использует заранее фиксированные
`center_radius=0.25` и `mutation_rate=0.1`. Предыдущий этап использовал
вложенный подбор этих настроек; его численные результаты относятся к другому
протоколу.

При трёх изменяемых ширинах разброс между seed уменьшился до 0,0000071,
однако парная RMSE стала выше исходной на медианные 0,85%. Увеличение бюджета
с 24×40 до 48×120 практически не изменило точность. Штраф уменьшил ухудшение
до 0,72%, но выигрыша относительно исходной модели на внешней физической CV
не дал. Перед финальным обучением на всех 26 точках внутренний подбор
во всех пяти запусках выбрал нулевой штраф. На теоретическом эталоне три
ширины улучшили RMSE примерно на 1,64%.

На кривых обучения среднее число обучающих наблюдений растёт с 10,8 до 20,8.
Средняя внешняя RMSE исходной модели уменьшается с 0,22392 до 0,14726;
у широкой настройки — с 0,21546 до 0,14240. Это показывает пользу большего
числа доступных физических наблюдений в исследованном диапазоне.

В анализе 35 строк исходная RMSE на внешних физических фолдах — 0,18902,
у широкой настройки — 0,18278, у трёх ширин — 0,18908. Статус девяти
исключённых строк требует проверки перед включением в основной набор.

Проверки выполнены на Windows x64 / CPython 3.14.7: 147 C++-тестов,
28 тестов GA-биндинга и 154 Python-теста прошли. Формула штрафа проверена
для MSE/RMSE/MAE, отдельный тест воспроизводит нечисловой прогноз
на экстремальной ранее исключённой точке.

## Автоматические проверки

```powershell
& "$experimentVenv\bin\python.exe" -m pytest -q
```

OpenFLL и NumPy проверяются на всех 60 000 точках шести поверхностей, на полном проходе по `P` и на всех тестовых прогнозах кросс-валидации. Simpful проверяется на всех 26 точках итоговой модели и на стратифицированной выборке из 300 точек поверхностей.

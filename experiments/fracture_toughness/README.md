# Валидация нечеткой поверхности трещиностойкости

Этот эксперимент воспроизводит первый практический этап, описанный в прилагаемой
статье: аппроксимацию Такаги — Сугено нулевого порядка для `KIC(P, a, c)`, построенную
непосредственно на основе очищенных экспериментальных данных без кластеризации.

## Варианты воспроизведения

- Набор данных содержит 26 сохраненных вручную наблюдений из прилагаемого
  блокнота. Исходный файл с 35 строками не перезаписывается.
- Для пористости `P` используются три гауссовых нечетких множества, а для `a` и `c` — по одному гауссову множеству для каждого наблюдения.
- Каждое наблюдение определяет одно правило и один константный консеквент.
- В OpenFLL, Simpful и независимом оракуле NumPy в качестве конъюнкции явно используется t-норма произведения.
- Ширина гауссовых распределений — это детерминированные начальные значения. Расстояние между соседними точками рассчитано таким образом, чтобы в середине интервала значение принадлежности составляло 0,5, а нижняя граница диапазона составляла 5 %, чтобы избежать появления непокрытых областей. Последующая генетическая оптимизация центров и ширин, описанная в статье, намеренно вынесена за рамки этого первого этапа воспроизведения.

В эксперименте приводятся только внутривыборочные показатели аппроксимации. Они воспроизводят построенную поверхность. Также сообщается о проверке методом исключения одного варианта, но при этом
используются только три экспериментально измеренных уровня пористости, и, следовательно,
прогнозирование для промежуточных концентраций материала не проверяется.

## Windows MSYS2 Python 3.14

Исходный модуль собран для MSYS2/UCRT64 Python 3.14. Подходящую изолированную среду можно создать с помощью:

```powershell
$venv = Join-Path $env:TEMP 'openfll-py314-fracture-exp'
C:\msys64\ucrt64\bin\python.exe -m venv --system-site-packages $venv
& "$venv\bin\python.exe" -m pip install --no-deps -r experiments\fracture_toughness\requirements.txt
```

Запустите эксперимент из корневого каталога репозитория:

```powershell
$env:PYTHONPATH = "$(Get-Location)\src;$(Get-Location)"
$env:PATH = "C:\msys64\ucrt64\bin;$env:PATH"
& "$env:TEMP\openfll-py314-fracture-exp\bin\python.exe" `
  -m experiments.fracture_toughness.run_experiment
```

Результаты записываются в `experiments/fracture_toughness/results/`.

OpenFLL и оракул NumPy оцениваются на всех 30 000 точках поверхности. Simpful
оценивается на всех обучающих наблюдениях плюс детерминированная стратифицированная выборка из 300 точек поверхности, поскольку оценка правил на Python выполняется значительно медленнее.

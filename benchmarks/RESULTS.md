# Отчёт по исследованию производительности инференса OpenFLL Python API

В настоящем документе представлены результаты сравнительного бенчмаркинга скорости вывода нечётких моделей библиотеки OpenFLL при различных сценариях использования: поэлементный вызов в Python-цикле (Scalar Loop), вызов через универсальный метод `predict` и нативный пакетный инференс `predict_batch`.

---

## 1. Методология и условия эксперимента

* **Тестовый стенд**:
  * ОС: Windows 11 Pro x64.
  * Интерпретатор: MSYS2 UCRT64 Python 3.14.7, NumPy 2.5.3.
  * Компилятор: GCC 14.2 (MinGW-w64 x86_64).
  * Процессор: Intel Core (гибридная архитектура 14 ядер / 20 потоков).
* **Модель**:
  * Нечёткая модель Сугено нулевого порядка (2 входа, 1 выход, треугольные и гауссовы функции принадлежности).
* **Набор данных**:
  * Синтетические равномерно распределённые точки в активной области функций принадлежности (`np.random.default_rng(42)`).
* **Процедура измерений**:
  * Обязательный предварительный прогрев (warm-up run).
  * Отключение автоматического сборщика мусора (`gc.disable()`) во время замера.
  * 5 независимых итераций с вычислением медианного времени (median wall time).

## 3. Анализ и техническая интерпретация

1. **Проблема границы Python/C++**:
   * При поэлементной обработке в цикле интерпретатора Python на каждый сэмпл приходится минимум 4 перехода FFI (вызовы pybind11 методов `set_input`, `calculate`, `get_output`). Дополнительные расходы создают упаковка/распаковка словарей и проверка типов в CPython.
   * Как следствие, максимальная скорость скалярного цикла ограничена значением около 0.76–1.05 млн сэмплов в секунду.
2. **Преимущество пакетного инференса (`predict_batch`)**:
   * Вся матрица данных NumPy передаётся в нативное C++ расширение за один вызов по прямому указателю на непрерывную область памяти (`py::array_t`).
   * Внутренний цикл обхода сэмплов выполняется в оптимизированном машинном коде C++ без участия Python-рантайма.
   * Время расчёта одной точки снижается до **80–90 наносекунд**, а пиковая производительность достигает **11–12.5 млн сэмплов в секунду**.
